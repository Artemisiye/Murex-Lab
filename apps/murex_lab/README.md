# 🧪 Murex Lab (App)

This is the main application folder for `Murex Lab`. 

## 🏗️ Structure
- **`app.py`**: The Flask backend and Capsule entry point.
- **`static/`**: CSS, JS, Images.
- **`templates/`**: HTML files.
- **`modules/`**: Python game logic (Crafting, World, Economy).
- **`data/`**: JSON configuration files (Items, Recipes, Quests).

## 🏃 Execution
To run this game in development mode:
```bash
python app.py
```
This will launch the native window via the Engine.
